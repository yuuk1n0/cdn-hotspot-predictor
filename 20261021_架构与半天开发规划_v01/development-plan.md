# 半天开发顺序与任务卡索引

版本：20261021 v01。本文是后续编码计划，不表示功能已经实施。现状及并行真实算法改动见[architecture.md](architecture.md)。

## 1. 目标、开工前提与最小闭环

用户选择：**考核广度优先**；外部资料和凭证可提供；飞书群机器人Webhook；大模型支持工具调用；人工登记效果；真实回测流程使用Mock预测；Agent建议后人工确认正式模型切换。

第一个闭环：浏览器上传真实小CSV → Python真实解析与落盘 → 页面取得READY datasetId和质量报告 → Vue提交既有Java预测接口 → Java主动请求Python Mock → Java事务保存Top50 → 页面自动显示本次runId、来源、日周窗口与精确B。

不重新搭工程，不重写已有导入、任务、轮询、结果校验和快照。开工前确认：JDK21、Node24、现有Conda、目标MySQL已完成003/004；默认Java8导致运行失败时只为本进程选择已安装JDK，不擅自安装或改全局设置。

本仓库有其他未提交工作。本轮只交付文档；后续开始编码时先核对git状态及真实算法适配验收，保留新增兼容字段。不能把本计划当成撤销其他工作的授权。

## 4. 可行性、降级与缺口

| 风险或前提 | 半天内最小可演示方式 | 仍未通过的正式要求 |
|---|---|---|
| 新业务大多从零开始，21张编码卡远多于稳定开发容量 | 先保P0，各P1只做模块文档定义的最薄真实逻辑；时间到即记录实际状态 | 不能承诺4小时高质量完成所有P1；不能用固定返回冒充功能 |
| CStore协议/key映射或凭证未实际拿到 | 文件详情显示IDENTITY_UNRESOLVED/未接入；可登记有来源的TEST大小证据 | 真实文件信息、预览、下载仍未验收 |
| 现有CSV不是已确认完整半年Top100；10066大且单位待确认 | 用仓库10350小数据；保留缺日和完整性警告 | 正式数据覆盖和真实预测论证未完成 |
| 本阶段用Mock | 保持真实异步链路、真实回测执行器和评价函数；明显标记模拟 | 多真实模型比较、准确率结论、正式模型替换未完成 |
| 无七/三十天真实成熟观察 | 使用有出处的历史TEST压缩/观测记录演示公式；真实新记录显示待观察 | 真实有效压缩数量、真实长期收益和账单归因未完成 |
| 飞书/模型网络失败 | 发送记录可查，Agent显示依赖失败；不降级固定答案 | 真实外部集成验收未完成 |
| 无当日预测 | 定时任务记录无当日业务数据；手动发送历史DEMO清单，标题写清日期/来源 | 不声称“今天的真实清单” |

每个时间盒结束记录：完成的任务ID、可用接口、实际操作证据、未通过项。若P0未通过，不开展后续P1；若P1超时，停止该模块的扩展并保留缺口，在剩余预算内按顺序评估后续可独立项。依赖未完成的模块只能说明阻断原因，不能展示假成功。T22预留不挪用。
