## 4. UI Mock 与未实现交互

- 五页默认演示值统一来自独立 UI fixtures，展示 `UI MOCK`/静态样例标记；按 App 独立切换。真实接口数据在独立区域呈现，来源以原响应字段为准。
- 总览数字为固定样例窗口；日期筛选用于 UI/样例趋势展示，不伪装为后台查询或重新计算全部指标。
- 预测页展示 8 条版式样例；“返回 50 条”明确标为静态指标，不代表已创建或完成任务。日榜是截止日后的下一日；周榜是随后连续七天累计。
- 回测排名和指标是方案样例，不能用于正式选模。样例最佳模型按 App 不同，不宣称复杂模型必然更优。
- 压缩率、预计净收益、前后访问图均为 UI 样例；未登记真实压缩大小、质量、成本或实际收益。两张对比插画不可播放，并非实际媒体输出。
- 开始预测（UI 演示）、开始回测、标记压缩只显示说明；预览、下载打开详情并告知未接入。压缩登记按钮禁用，不保存记录。
- Agent 发送只形成页面内存消息并展示“未连接 LLM 或实时业务工具”；不查询实时数据、不生成报告、不调用模型、不切换模型。
