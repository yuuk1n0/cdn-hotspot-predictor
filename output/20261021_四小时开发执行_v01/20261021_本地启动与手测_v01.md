## 服务停止后手动启动

以下在WSL/bash执行，四个终端各运行一项，按MySQL→Python→Java→Vue顺序启动。使用已有环境，不需要重新安装依赖或执行数据库SQL。保持每个服务单实例，不在已有进程运行时再次启动。

### 终端1：MySQL

```bash
cd /home/yukino/projects/work/cvte/cdn-hotspot-predictor
mysqld --no-defaults \
  --datadir="$PWD/runtime/mysql" \
  --socket=/tmp/cdn-hotspot-local-mysql.sock \
  --port=13306 \
  --bind-address=127.0.0.1
```

使用已有数据目录；不要执行初始化、schema.sql、data.sql或重复迁移。

### 终端2：Python

```bash
cd /home/yukino/projects/work/cvte/cdn-hotspot-predictor/predictor
PREDICTION_MODE=MODEL \
PREDICTION_MODEL_VERSION=hotspot-simple-v1 \
/home/yukino/miniconda3/envs/cdn-predictor/bin/python \
  -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

沿用当前本地部署的MODEL版本，数据目录默认是项目runtime/predictor。不要同时启动两个进程操作此目录。

### 终端3：Java

```bash
cd /home/yukino/projects/work/cvte/cdn-hotspot-predictor/backend
export JAVA_HOME=/home/yukino/.sdkman/candidates/java/21.0.4-tem
export PATH="$JAVA_HOME/bin:$PATH"
MYSQL_HOST=127.0.0.1 \
MYSQL_PORT=13306 \
MYSQL_DATABASE=cdn_hotspot \
MYSQL_USER=cdn \
PYTHON_BASE_URL=http://127.0.0.1:8000 \
SPRING_SQL_INIT_MODE=never \
mvn -o spring-boot:run
```

当前本机开发库沿用既有用户和密码配置；没有设置MYSQL_PASSWORD时application.yml使用现有开发默认值。根.env不自动读取。这个命令从当前源码编译运行，避免直接运行旧JAR遗漏新接口。

### 终端4：Vue

```bash
cd /home/yukino/projects/work/cvte/cdn-hotspot-predictor/frontend
export PATH=/home/yukino/.nvm/versions/node/v24.14.0/bin:$PATH
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

打开http://localhost:5173。strictPort避免端口占用时悄悄改成5174，造成来源校验失败。
