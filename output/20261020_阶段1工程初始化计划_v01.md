# 阶段 1 工程初始化实施计划

> 按当前会话内联执行。每项行为代码遵循测试先行；配置与脚手架通过构建和运行命令验证。未经额外批准不提交 Git。

**目标：** 建立 Vue 3、Spring Boot + MySQL、FastAPI 三个可独立启动的最小工程并完成健康检查联调。

**架构：** Vue 通过 Vite 的 `/api` 与 `/data-api` 代理分别访问 Java 和 Python。Java 健康检查执行 MySQL `SELECT 1`；Python 提供独立健康检查。阶段 1 不包含任何业务 API。

**技术栈：** Vue 3、Vite、Node 内置测试；Java 21、Spring Boot 3.3.5、Maven、MySQL 8；Python 3.11、FastAPI、Uvicorn、Pytest、Conda。

## 全局约束

- CSV 文件不经过 Java。
- 当前阶段不实现 CSV 导入、预测、榜单或业务持久化。
- 不引入 Redis、消息队列、微服务治理或额外框架。
- Python 环境名固定为 `cdn-predictor`，不使用 Conda `base` 运行。
- 保留用户现有暂存和删除状态，不修改 `datasets/` 与 `materials/`。
