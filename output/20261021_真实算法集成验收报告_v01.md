# 真实 v1 算法集成验收报告

## 结论与范围

已按用户批准的第一阶段建议，在原有 FastAPI 异步任务、Java 任务编排与快照查询、Vue 结果查询链路中接入 `hotspot-simple-v1`。真实结果为 `predictionSource=MODEL`、`resultMode=REAL`；Mock 为 MOCK/MOCK。没有修改数据库结构、业务数据库内容、原始交付目录、依赖或全局配置；没有提交、推送或合并。

默认启动仍为 Mock；真实模式必须显式设置下面两个环境变量。未替用户重启现有业务服务；跨服务验证使用临时 Python 进程及隔离 H2，不是对现有业务 MySQL 的验收，也未进行浏览器端到端验收。

## 实际计算与数据流

```text
既有 CSV 上传 → Python ImportStore → READY normalized.csv
Java 接收预测请求并持久化 taskId
→ Python 持久队列（同一 taskId）
→ algorithm_adapter：指定 App + date≤cutoffDate
→ 疑似截断识别、冷启动、过去数据独立选型/证据已成熟的审阅配置
→ v1 历史观测强度外推、完整候选、稳定流量排序
→ PredictionStore 原子发布 result.json 和 runId
→ Java 轮询成功、读取前50、校验与精确求和
→ 原 prediction_run 快照事务发布
→ Vue 查询 taskId/runId 并显示 REAL/MOCK
```

v1 支持最近观测、7日均值、3日快速衰减、14日衰减及 App/周期独立配置。日结果为下一自然日，周结果为后续连续7日累计；候选不足50时不凑数。未知预测分数、文件大小、类型和压缩状态保留 null。

真实计算发生在 Python；没有引入 Python MySQL 访问、CLI 子进程、MQ、Redis、Celery 或第二套调度。

## 时间边界、追溯与失败处理

- 所有质量判断和模型选择之前，先过滤 App 和 cutoffDate；追加未来日期不会改变疑似截断处理或当前预测。
- 使用测试期结果决定推广的配置，要求最后测试切点 + horizonDays 不晚于预测截止日；更早截止日改用当时已知历史独立选型。纯 train 选型文件仍按选择标签边界校验。
- 服务启动时捕获加载算法和配置摘要，新任务绑定该摘要。运行中更换磁盘文件后，新旧真实任务均拒绝执行；重启后不同摘要的旧排队任务也失败为 MODEL_ARTIFACT_CHANGED。完整历史运行继续可查。
- 独立只读审查发现“新磁盘摘要对应旧内存代码”的追溯漏洞，本轮已补回归并修复；不把旧加载代码标为新摘要。
- MODEL 只允许 hotspot-simple-v1。v2/v3、错 App、错版本、缺少近期历史和计算异常均明确失败，不能回退 Mock。
- 原始任务、全候选发布、恢复与 Java 快照事务规则保留；未知来源/冲突模式和损坏元信息不作为有效结果。

## 启动、预测和回退

在项目根目录执行（使用已存在的 cdn-predictor 环境）：

```bash
cd predictor
PREDICTION_MODE=MODEL PREDICTION_MODEL_VERSION=hotspot-simple-v1 \
  conda run --no-capture-output -n cdn-predictor \
  python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Java、Vue沿用现有启动方式。已有业务服务占用端口时由运行者停止原进程再重启；不要同时使用同一个持久目录启动两个Python实例。

导入10350 CSV，轮询到SUCCEEDED/READY后，用实际datasetId替换以下占位，向Java提交：

```bash
curl -i http://127.0.0.1:8080/api/v1/predictions \
  -H 'Content-Type: application/json' -H 'Idempotency-Key: real-10350-h7-v1' \
  -d '{"datasetId":"ds_replace_with_ready_dataset_id","appId":"10350","cutoffDate":"2026-10-06","horizonDays":7,"modelVersion":"hotspot-simple-v1"}'
```

查询Java `/api/v1/tasks/{taskId}`，成功后查询 `/api/v1/predictions/{runId}`。Vue已有面板输入taskId/runId即可。日预测使用horizonDays=1和新的幂等键；同键重试必须保持全部业务参数一致。

回退时停止该Python进程，仍在predictor目录运行：

```bash
PREDICTION_MODE=MOCK PREDICTION_MODEL_VERSION=contract-demo-v1 \
  conda run --no-capture-output -n cdn-predictor \
  python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

新请求也改用contract-demo-v1及新幂等键；已接收任务和历史运行不改模式、不删除。完整CSV上传和查询示例见 predictor/README.md。
