## 手动上传

1. 打开 http://localhost:5173 。
2. 若显示上次接收记录，点击“选择另一份文件”。
3. 在“上传流量观测文件”选择项目 `datasets/10350.csv`，或自己的非空 CSV，大小不超过 5 MiB、数据行不超过 20000。
4. 对 10350.csv 保持 REAL 来源及默认字段映射，并选择“B · 已确认是字节”。其他 CSV 按实际表头修改映射；没有 App 列时清空 App 列映射并填写默认 App ID。
5. 点击“上传 CSV”。预期出现 importTaskId；这只代表请求已接收，不表示解析成功，且不会自动改变下方 Fake 榜单。
6. 复制编号，在浏览器打开 `http://localhost:5173/data-api/imports/<importTaskId>`。SUCCEEDED 后读取 datasetId，再打开 `/data-api/datasets/<datasetId>/quality` 查看报告。需将尖括号及其内容替换为实际编号。

当前页面缺少预测提交表单。若继续手动测试完整接口链路，可在浏览器开发者工具控制台执行以下代码；必须先替换 datasetId、App、截止日，并确保截止日在对应 App 的观测范围内。执行会新增一个预测业务任务。

```javascript
const response = await fetch('/api/predictions', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Idempotency-Key': crypto.randomUUID()
  },
  body: JSON.stringify({
    datasetId: '替换为成功导入的datasetId',
    appId: '10350',
    cutoffDate: '2026-10-06',
    horizonDays: 7,
    modelVersion: 'contract-demo-v1'
  })
});
console.log(response.status, await response.json());
```

复制返回的 taskId，在“预测任务与本次榜单”查询，即可轮询 Java 任务并读取成功快照。上述代码每次执行生成新幂等键；同一次请求若响应丢失需沿用原键重试，不重复执行此示例创建新业务任务。
