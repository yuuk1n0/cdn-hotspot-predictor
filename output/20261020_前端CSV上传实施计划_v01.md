# 前端 CSV 上传实施计划

**范围：** 依据用户最新指示，本轮只开发前端上传功能，不修改 Python、Java、数据库或设计文档。沿用现有 Vue 页面、配色、表格和 Vite `/data-api` 代理，不新增依赖。

**设计：** 在现有 Top50 筛选区之前加入独立上传面板，展示“选择文件 → 提交中 → 已接收 / 失败”。原有 FAKE 榜单保留自己的来源标识。浏览器不解析 CSV，不推测文件名对应的 App；202 只表示接收，不表示导入完成。

**契约：** multipart 上传 `/data-api/imports`，带 `Idempotency-Key`、file、mapping、datasetType=FILE_DAILY、datasetSource、sourceUnit 和可选 appId。收到 202 和合法 importTaskId 后仅保存编号。不实现状态查询、质量报告、数据集或预测。上传失败后原文件和配置不变时重试沿用原幂等键。

**视觉：** 复用背景 #06151b、面板 #0a1f27、正文 #d8e9e7、状态青色 #2ed3b7 和警告橙色 #ffb178；沿用 Microsoft YaHei 正文与 Cascadia Code 标识字体。独立回执区突出返回的任务编号，不重做看板。
