# 10350 文件日数据与 LightGBM v3 实验

数据：`dataset/10350 (1).csv`，AppID 10350；调用时按 B 读取。日期 2026-01-05 至 2026-10-13，共 248 个有记录日期、4,478 条文件日记录、952 个文件；每天文件数中位数为 13。

## 数据特征

未来 7 日原测试期（2026-08-12 至 2026-10-06，56 个切点）每个窗口平均有 44.8 个未来文件。其热门 Top 50 中平均 39.8% 的文件在切点之前从未出现，无法由历史文件候选池预测。固定回看 30 日的候选覆盖率为 55.7%，回看全部历史为 60.2%；现有 v1 自适应候选池为 43.6%。但把 v1 固定改成 30 日候选窗口后，测试期 Recall@50 从 39.85% 略降至 39.60%，NDCG@50 从 58.59% 略降至 58.42%；因此 v3 仍沿用 v1 候选池。

v2 只在未来仍有记录的候选文件中学习相对流量，没有看到候选文件在未来消失的情况。按本数据口径，v3 将**有记录的完整未来日期内未出现的候选文件**作为零流量样本。未记录的整个日历日仍不能作为标签。v3 保留 v1 的强历史流量排序，再与 LightGBM 排名等权融合；模型仍在每个切点只用已结束的历史标签窗口训练。

## 时间滚动回测

| 预测期 | 方法 | Recall@50 | NDCG@50 | 文件流量覆盖率@50 | 候选覆盖率@50 |
| --- | --- | ---: | ---: | ---: | ---: |
| 次日，71 个切点 | v1 `last_day` | 71.61% | 76.43% | 90.97% | 75.59% |
| 次日，71 个切点 | v2 | 68.75% | 74.27% | 90.89% | 75.59% |
| 次日，71 个切点 | v3 | 71.61% | 76.81% | 90.70% | 75.59% |
| 未来 7 日，56 个切点 | v1 `last_day` | 39.85% | 58.59% | 81.26% | 43.59% |
| 未来 7 日，56 个切点 | v2 | 39.70% | 55.18% | 80.56% | 43.59% |
| 未来 7 日，56 个切点 | v3 | 40.06% | 59.85% | 80.89% | 43.59% |

v3 在两个周期均提高 NDCG；次日 Recall 基本相同，7 日 Recall 仅提高约 0.21 个百分点。文件流量覆盖率略降，因此不应将其解释为对所有业务指标都有改进。原测试期已经用于 v2 分析和本次探索，不再是完全未查看的测试集；需要后续新数据检验是否能保持收益。当前保持 v1 为默认模型，v3 作为可选实验版本。

逐切点 v3 结果在本地生成的 `results/10350-v3-backtest-h1.json` 和 `results/10350-v3-backtest-h7.json`；v1/v2 对照见 `results/10350-compare-h1.json` 和 `results/10350-compare-h7.json`。复现命令：

```bash
for horizon in 1 7; do
  ./scripts/backtest.sh --model-version hotspot-lightgbm-v3 \
    --input 'dataset/10350 (1).csv' --app-id 10350 --source-unit B \
    --horizon-days "$horizon" --output "results/10350-v3-backtest-h${horizon}.json"
done
```
